# Semiconductor Band Diagram Visualizer

An interactive website for exploring how semiconductor energy bands respond to doping and applied voltage. Pick a material (Si, GaAs, …), set doping levels, and see the conduction, valence, intrinsic and Fermi levels with the gaps between them. Switch to a pn-junction to see band bending, the built-in potential (qV<sub>bi</sub>), the electric field direction, the depletion region (x<sub>p</sub>, x<sub>n</sub>, W), and animated drift and diffusion of electrons and holes under forward or reverse bias.

## Running it

No build step. Open `index.html` in a browser, or visit the GitHub Pages site for this repository.

Fonts (Schibsted Grotesk, STIX Two Text) are bundled in `fonts/` under their own licenses.
